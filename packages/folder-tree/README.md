# @kanban/folder-tree

Drag-and-drop tree of folders and items over `@hello-pangea/dnd`, used by the
sidebar's board list. `useFolderTree` holds the tree and its collapsed folders;
`DraggableFolders` renders it and turns drops into `TreeMove`s.

Vendored from `react-draggable-folders` 0.0.3 (MIT, see `LICENSE`).
